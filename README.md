# RPG Terminal - Sistema Testável com POO

Projeto prático de engenharia de software focado em **arquitetura orientada a objetos** e **testes unitários automatizados**. Desenvolvido para consolidar competências técnicas de backend e validação de regras de negócio.

## 🎯 Competências Demonstradas
- **Testes Unitários (pytest)**: Validação de edge cases críticos e contratos de comportamento.
- **POO Aplicada**: Herança, polimorfismo e encapsulamento em domínio real.
- **Interface Pública Segura**: Métodos e propriedades que protegem a integridade dos dados internos.
- **Design Orientado a Testes**: Código estruturado para ser testável desde a primeira linha.

## 🧪 Executando os Testes
```bash
pip install pytest
pytest tests/ -v --tb=short
